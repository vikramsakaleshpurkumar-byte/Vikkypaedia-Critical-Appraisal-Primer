# Publication privacy check

The local course bundle was checked for personal computer paths, common credential-token patterns, saved learner export files and private paths in the original PDF metadata. None were found by these checks.

Learner answers, reflections and practice state live in each learner's browser storage; they are not embedded in the uploaded static course. Optional exported learner records are not included in this bundle. No remote learner-data service is connected.

Vikkypaedia branding remains as requested. Public bibliographic sources, author names, source institutions, figure credits and copyright notices remain intact. The course and its sources have **not** been made anonymous. Required source credits must not be stripped to disguise source material. The package still includes the supplied textbook and reproduced source assets; this check does not establish redistribution permission.

This was a pattern-based local check, not a forensic privacy audit or publication-rights certification. No GitHub upload or public deployment was performed.
