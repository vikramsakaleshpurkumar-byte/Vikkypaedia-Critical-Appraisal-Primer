# Module 2: Searching the literature

Audience: Healthcare students, practitioners and research learners. Beginners can start with units 1–5; experienced learners can select a relevant topic.
Prerequisites: No advanced statistics assumed. Later units benefit from the question, design, bias and uncertainty foundations in units 1–5.
Need: You have ten minutes for a clinical answer; your colleague is planning a comprehensive review. Should your searches be the same?
Competence sought: explain appraisal concepts, select a defensible response and articulate uncertainty. Knowledge and reasoning only; no claim of observed clinical performance.

Estimated effort: 25–40 minutes plus source reading; author estimate, not measured.
Review: 2026-11-06; model author, targeted source comparison. No specialist, psychometric, user or assistive-technology validation. No external update layer.

## Case stages and feedback

Reused stage 1: A librarian supports two projects about the same treatment. Project X needs an answer for tomorrow's consultation; project Y will claim a comprehensive map of the research. Both have found the same credible recent synthesis. Which difference in stopping rules is most defensible?

Feedback: Search purpose sets the completeness requirement; a useful answer and a comprehensive evidence map are different products. (PDF 36). Response required before feedback; Continue before next stage.

Reused stage 2: A trainee searches a familiar database with two text words and retrieves no relevant primary studies. A suitable secondary source contains several apparently eligible studies not retrieved. What is the most informative first response?

Feedback: Known relevant records can reveal missing concepts, indexing or syntax before the search is judged adequate. (PDF 42). Response required before feedback; Continue before next stage.

## Retrieval, visuals and evaluation

Six authored cards and five distinct authored questions. No automated questions. Later retrieval suggestions reuse these objects and Anki; no scheduler. Original figures, tables and complete page images remain in the reader. Visual spotter is reference interpretation with caption reveal; no validated visual examination claim. No synthetic clinical data or observed patient records.

Browser-local completion and reflections can be exported. Clarity, remaining confusion and application are prompted in the reflection; no remote collection or analytics. Question-level distractor feedback is available after response. Same-item retries have practice effects. Each depth is a route through two units; not a separate qualification.

Accessibility target: keyboard operation, named controls, visible focus, text explanations, reflow and reduced motion. Actual tested and untested aspects are in ../curriculum_review.md. No WCAG certification claim.
Remaining review: faculty subject review, stronger distractor piloting, fuller explanatory lessons for advanced topics, screen-reader review and learner usability evaluation. Source-edition AI examples and external-resource descriptions may age; verify separately before formal teaching.
