# Progressive capstone — assessment version 2

One fictional programme decision in three stages. Each stage presents five plausible alternatives and requires a response before feedback and continuation. Future findings are not rendered before the relevant stage.

## Stage 1: Define the decision before the search

A fictional clinic currently offers usual follow-up. It is considering a home-monitoring programme that also requires extra clinic visits. A frail adult asks whether it is worth joining to avoid hospital admissions over the next year.

Task: Which question best matches this person’s comparative decision?

Best-response reasoning: This preserves the relevant population, programme contrast, outcome, burden and one-year horizon.

## Stage 2: Translate the effect to a different baseline risk

A fictional randomised trial reports admissions at one year in 20/100 usual-care participants and 10/100 programme participants. The clinician estimates this person's usual-care admission risk at 4%. For this arithmetic exercise only, assume the trial's relative effect transfers unchanged.

Task: Under that assumption, what absolute benefit and NNT follow for this person’s baseline risk?

Best-response reasoning: Trial RR is 0.10/0.20 = 0.5. Applied to 4%, treated risk is 2%; ARR is 2 points and NNT is 1/0.02 = 50.

Source context: chapter 22, PDF 335. Stage 3 also uses the appendix-2 arithmetic from stage 2.

## Stage 3: Put the absolute benefit beside a preference

The patient understands the estimates and says that, given the travel burden, joining would be worthwhile only for at least a three-percentage-point reduction in one-year admission risk. Continue using the preceding transport assumption; this is a fictional values exercise, not a clinical recommendation.

Task: Which interpretation correctly relates the calculated point benefit to this stated threshold?

Best-response reasoning: The assumed individual-context ARR is 4% − 2% = 2 percentage points. A stated three-point minimum is not met by that point estimate; uncertainty and preferences still belong in discussion.

Source context: chapter 16, PDF 259. Stage 3 also uses the appendix-2 arithmetic from stage 2.
