## Case stages and feedback

Reused stage 1: A new diagnostic test is evaluated using only clear-cut severe cases and healthy volunteers. The intended clinic population mostly has borderline symptoms and competing diagnoses. Which change most directly improves the relevance of the validation?

Feedback: The target spectrum includes diagnostic uncertainty; extreme groups can overstate performance in routine use. (PDF 135). Response required before feedback; Continue before next stage.

Reused stage 2: The new index test contributes to the reference diagnosis against which its accuracy is measured. The index result is interpreted reproducibly and the sample is large. Which modification most directly improves the validity of the comparison?

Feedback: The index must not partly define its own correctness; reproducibility and size do not remove circularity. (PDF 135). Response required before feedback; Continue before next stage.
